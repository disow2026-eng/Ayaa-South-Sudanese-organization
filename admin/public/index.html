📘 AYAA Admin — Complete Guide

Everything you need to manage your website

Quick Start — 4 Steps

1

Pick a page — click any page name in the Pages tab (left sidebar). It loads in the preview window.

2

Turn on Edit Mode — click the Edit Mode button in the toolbar above the page, or press Ctrl E. Purple outlines appear on everything you can change.

3

Make your changes — click text to edit it, hover over sections for controls, right-click anything for options.

4

Save — press Ctrl S or click the Save button (top right). A green dot means unsaved changes.

Undo & Redo

1

Made a mistake? Press Ctrl Z to undo it. Up to 40 steps are saved in history.

2

Changed your mind? Press Ctrl Y to redo what you just undid.

⚠️ Undo history disappears when you reload the page. Always Save before reloading.

Keyboard Shortcuts

Save pageCtrl S
Toggle Edit ModeCtrl E
Undo last actionCtrl Z
Redo actionCtrl Y
Bold selected textCtrl B
Close any popupEsc

Editing Text

1

Turn on Edit Mode, then click any text on the page. Headings, paragraphs, button labels, captions — all editable.

2

Just start typing to replace the text. Press Enter for a new line.

3

Use the dark format bar above the page to change: Bold · Italic · Font size · Alignment · Text color · Background color.

Add brand-new text: click the green + Add Text button in the format bar, or just double-click any blank area on the page.

Sections & Cards

1

In Edit Mode, hover over any section (a full row block). Three buttons appear in the top-right corner: ↑ Up · ↓ Down · Delete.

2

To remove a single card (one box inside a grid), hover directly over that card — a red "Remove card" button appears on it.

3

To add a new section, open the Add tab in the sidebar and click any block type.

Deleted something? Press Ctrl Z immediately to bring it back.

Navigation Links

1

Open the Nav tab to see all menu links. Click the pencil icon to rename a link or change its URL.

2

Click + Add tab to add a new menu item. Fill in the label and the page it links to (e.g. about.html).

3

Click Sync nav to all pages to apply the same menu to every page on the site at once.

Always sync after adding or removing links so every page stays up to date.

Uploading Images & Videos

1

Click the Media tab (Images icon) in the sidebar.

2

Drag files from your computer onto the upload box, or click it to browse and select files.

3

Supported files: JPG, PNG, WEBP, SVG for images — MP4, MOV, WEBM for videos.

Videos can be up to 500 MB. Images up to 500 MB too. Larger files take a moment to upload — wait for the green confirmation.

Placing Media on the Page

1

Turn on Edit Mode first.

2

In the Media tab, find the image or video you want. Click and drag it from the sidebar directly onto the page.

3

Drop it where you want it. Images appear as photos; videos appear with a built-in play button so visitors can watch them.

To replace an image already on the page, right-click it in Edit Mode and choose "Replace image".

Section Background Photos

1

In Edit Mode, click any text inside the section you want to add a background photo to.

2

In the format bar, click "Section Photo" — a picker opens. Click any uploaded image to set it as the background.

3

To remove it, click the same text element, then click "Remove Photo" in the format bar.

Use high-quality wide photos for best results. The image auto-fills and centers itself.

In Edit Mode, right-clicking anything on the page opens a smart menu with actions for that specific element. No need to hunt for buttons — just right-click!

Right-click an ImageReplace the image, copy its filename, or delete it from the page.

Right-click a LinkEdit the URL it points to, or remove the link while keeping the text.

Right-click TextAdd a new text block above or below it, or delete that text element entirely.

Right-click a CardDuplicate it (creates an identical copy next to it) or remove it from the page.

Right-click a SectionMove it up or down the page, duplicate the whole section, or delete it.

TipIf you delete something by accident, press Ctrl Z right away to bring it back.

Publishing to the Live Website

1

Save all your pages first using Ctrl S on each one. Unsaved pages won't go live.

2

Click the Go Live button in the top-right corner (the green rocket button).

3

Wait 1–2 minutes. Your site will update automatically. You'll see a green confirmation message.

⚠️ Needs a Netlify Deploy Hook URL in the Settings tab. Ask your developer if the Go Live button isn't working.

SEO — Getting Found on Google

1

Open the Meta tab in the sidebar while any page is loaded.

2

Page Title — this appears in browser tabs and Google search results. Make it descriptive (e.g. "About Us — AYAA South Sudan").

3

Meta Description — the 1–2 sentence summary shown under your link in Google. Keep it under 160 characters.

4

Fill in Social Title & Description so links look great when shared on Facebook, WhatsApp, etc.

Click Save Meta Tags then press Ctrl S to save the page. Do this for every page.

Creating New Pages

1

In the Pages tab, click + New page.

2

Enter a name (no spaces, e.g. gallery) and optionally copy the layout from an existing page.

3

The new page opens automatically. Use Edit Mode to add content, then add it to the Nav so visitors can find it.

Settings & Password

1

Open the Settings tab to change your admin password or save your Netlify deploy hook URL.

2

To change your password: type the new password in both fields and click Save Settings.

Keep your password secure. The default is ayaa2024 — change it as soon as possible.
